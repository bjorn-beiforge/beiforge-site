# beiforge-site

The public website for BeiForge, served at https://beiforge.com by GitHub Pages.

It is a plain static site: no build step, no framework, no monthly cost.

| File | What it is |
| --- | --- |
| `index.html` | The homepage. |
| `signalforge/index.html` | The SignalForge product page, served at /signalforge/. |
| `styles.css` | Layout and look. Brand colors and fonts are tokens at the top. |
| `assets/` | Bear-and-star mark and the favicons. |
| `CNAME` | Tells GitHub Pages to answer for beiforge.com. |

## Editing

Change the text in the page's `.html` file, commit, and push. GitHub Pages republishes in about a minute.

## Keep separate

This repo is public. SignalForge code and anything from client work stays in its own private repos.
